# Operational Incident Intelligence · v0.1.0

Official initial public release of an **independent, synthetic-data engineering lab**.

## Included

- Deterministic fictional incident records, severity categories, resolution status and SLA definitions.
- Synthetic backlog aging, overdue-open reporting and reproducible Python tests.
- Offline illustrative dashboard and accompanying BI reporting methodology.
- A separately generated [interactive portfolio demo](https://dicureck.github.io/?demo=incidents#lab), with filters and CSV download.

## Verification

The release is published only after the **Lab CI** GitHub Actions workflow verifies the source at the tagged commit.

## Limitations

No real support incidents, live monitoring agent, production alerting or customer SLA contracts. The browser demonstration and repository use separate invented fixtures.
